# 内部资料

> 推送者：Codex 2026-11-01

本目录保存不直接用于公开网站的焕琢、VARVAN 品牌资料。

## 目录

- `trademark/`：商标档案、查询方法、注册信息和审查报告。
- `product/`：产品需求、配方方向、打样要求和检测记录。
- `brand/`：品牌策略、命名方案、视觉提案和内部讨论。

## 重要说明

如果这个 GitHub 仓库本身是公开仓库，`internal/` 只是内容分类，不是权限保护。配方、供应商、成本、未公开商标和商业计划等敏感内容，应放到私有仓库、私有网盘或受控文档系统中。

无论目录名称是什么，都不要提交密码、API Key、访问令牌、客户个人信息和未授权素材。

## 迁移原则

现有根目录资料先保留原位，后续逐批迁入。迁移时不改正文结论，不删除历史提交，不覆盖其他人的文件。
