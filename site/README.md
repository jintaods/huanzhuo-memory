# 网站公开内容

> 推送者：Codex 2026-11-01

本目录只保存可以对外发布的网站内容。网站构建、部署配置和具体前端代码以后可以单独增加，不在这里放内部资料。

## 目录说明

| 目录 | 放什么 | 不放什么 |
|---|---|---|
| `content/` | 文案、产品介绍、品牌故事、FAQ、SEO 信息 | 配方、供应商、未公开商标信息 |
| `assets/` | 已确认可公开的图片、视频、字体、图标 | 内部提案、未授权素材、客户隐私 |
| `pages/` | 页面结构、区块顺序、CTA 和内容清单 | 与页面无关的零散笔记 |
| `apps/` | 可独立运行的单文件网页应用 | 内部工具和未公开数据 |

## 推荐流程

1. 在 `content/` 写内容和数据。
2. 在 `assets/` 放已确认授权的素材。
3. 在 `pages/` 写页面结构和引用关系。
4. 网站上线前检查所有链接、图片和文字是否已获准公开。

## 命名建议

- 文件名使用英文小写短横线，例如 `brand-story.md`、`product-serum.json`。
- 同一素材更新时使用版本后缀，例如 `hero-v2.jpg`，不要直接覆盖旧文件。
- 每份内容都写明 `status` 和 `updated`，方便判断是否可上线。
